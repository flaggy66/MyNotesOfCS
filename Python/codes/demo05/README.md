# 目录文件说明
本`demo05/`目录中的文件用于学习Python的文件读写与异常处理

## 目录结构

```
demo05/
├── poem.txt 要读写的文本文件
├── poem01.txt 要读写的文本文件
├── simple.json 简单数据的json存储文件
├── people.json 对象数据的json存储文件
├── readfile.py 读取文件poem.txt
├── writefile.py 写入文件poem01.txt
├── exception.py 学习异常处理
├── jsonstore.py JSON格式存储数据
├── README.md 目录文件说明
```
